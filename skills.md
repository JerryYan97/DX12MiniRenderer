## AI assistant and Coding Style
- Match existing code style in surrounding files.
- Prefer explicit initialization for GPU/resource structs.
- Use current naming style:
  - `m_` for members
  - `p` prefix for pointers where already used
- Keep functions compact and practical.
- Avoid introducing template-heavy abstractions unless clearly justified.
- Please be restrictive before deleting comments. Only delete or revise comments when the comments cannot match the code it tries to explain.
